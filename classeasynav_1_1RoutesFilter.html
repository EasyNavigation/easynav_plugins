Detailed Description

Base interface for all routes filters.

A RoutesFilter consumes the current navigation state (including the active RoutesMap written by RoutesMapsManager) and is allowed to modify other entries in the NavState (for example, a costmap) in order to enforce corridor-following behaviour, masking, etc.
