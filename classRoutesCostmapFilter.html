Detailed Description

Costmap filter that raises costs outside navigation routes.

This filter reads the current RoutesMap and a dynamic costmap ("map") from the NavState. All cells that do not lie within a configurable corridor around any route segment have their cost raised to at least min_cost_. A debug occupancy grid representing the filtered costmap is also published.

Apply the routes-based filtering to the costmap.

If both "routes" and "map" entries are present in the NavState, the costmap is modified in place and the debug occupancy grid is published. If either entry is missing, the function returns without making changes.
