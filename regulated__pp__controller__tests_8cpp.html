Apply curvature-based regulation on the linear velocity.

Slows the robot down when the path curvature radius is smaller than min_radius, so sharp turns are taken more conservatively.

◆ obstacleConstraint()

double obstacleConstraint ( const double raw_linear_vel,
const double min_obstacle_distance,
const double obstacle_scaling_dist,
const double obstacle_scaling_gain )

Apply obstacle-proximity regulation on the linear velocity.

EasyNav controllers do not have access to a costmap, so this heuristic replaces nav2_regulated_pure_pursuit_controller's cost-based regulation with an equivalent term based on the distance to the closest obstacle point observed by the robot's perception.

Parameters
raw_linear_velDesired linear velocity before regulation.
min_obstacle_distanceDistance (m) to the closest known obstacle ahead of the robot.
obstacle_scaling_distDistance below which the regulation is triggered.
obstacle_scaling_gainGain (<= 1.0) applied when scaling down the velocity.
Returns
Regulated linear velocity.
