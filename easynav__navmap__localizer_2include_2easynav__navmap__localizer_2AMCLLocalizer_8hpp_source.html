214 // that writes their poses, and the other (correct(), reseed(), the pose callbacks) the only one
215 // that writes their weights and hits. Poses computed outside the RT thread are handed over in a
216 // single slot: pending_poses_ is filled while pending_ is false, then pending_ is set; predict()
217 // applies them and clears it. The vector never changes size, so indices are always valid.
