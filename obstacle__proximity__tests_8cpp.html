How far the robot can move straight along its x axis before touching a perceived point.

Only the points in the corridor the robot sweeps (|y| < robot_radius) and on the side it moves towards count. Used to check that a straight escape (forward or backward) is clear.

Parameters
nav_stateCurrent navigation state.
direction+1 to move forward, -1 backward.
robot_radiusThe robot's circumscribed radius (m).
z_minPoints below this height (robot frame) are ignored.
z_maxPoints above this height (robot frame) are ignored.
Returns
The free distance (m): 0 if already touching, +infinity if nothing is in the way. Without any valid perception, 0 (nothing says it is clear).
